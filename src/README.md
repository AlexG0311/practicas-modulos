# Módulo de Asistencias — prototipo PWA

Componente React responsive para demostrar el flujo RF1–RF3:
- Estudiante: check-in, ubicación opcional y su historial.
- Supervisor: bandeja y validación/rechazo.
- Asesor: acumulado de horas, ausencias y pendientes.

## Integración realizada

El módulo ya está conectado al dashboard principal mediante el menú lateral de la aplicación. Cuando se selecciona la opción Asistencias, el contenido del dashboard se reemplaza por la vista del módulo.

## Archivo base de integración

Consulta [INTEGRACION.md](INTEGRACION.md) para revisar el flujo de integración, limitaciones y próximos pasos hacia backend real.

## Importante

Es un prototipo de frontend, no una PWA completa ni un sistema productivo. Requiere integración con el dashboard, backend, autenticación, base de datos, manifest/service worker e iconos para convertirse en una aplicación instalable y persistente.
